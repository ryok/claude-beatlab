## Tips

### 良いタイトルのパターン

- 「【技術名】〜する方法」
- 「【技術名】で〜を実装してみた」
- 「〜でハマったので解決策をまとめる」
- 「〜を○○倍高速化した話」
- 「初心者向け：〜入門」

### emoji の選び方

| カテゴリ | おすすめ emoji |
|---------|---------------|
| 開発ツール | 🛠️ ⚙️ 🔧 |
| Web | 🌐 💻 🖥️ |
| AI/ML | 🤖 🧠 ✨ |
| データ | 📊 📈 🗄️ |
| セキュリティ | 🔐 🛡️ 🔒 |
| パフォーマンス | 🚀 ⚡ 💨 |
| デバッグ | 🐛 🔍 💡 |
| 入門 | 📚 📝 🎓 |

### topics の選び方

- 具体的な技術名を優先（例: "react" > "frontend"）
- 最大5つまで
- 小文字で統一
- よく使われるタグ: javascript, typescript, python, react, nextjs, aws, docker, go, rust
